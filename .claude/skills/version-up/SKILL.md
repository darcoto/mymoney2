Вдигни минорната версия на приложението:

1. Прочети файла `VERSION` от root директорията на проекта
2. Парсни версията като `major.minor` (например `1.3`)
3. Увеличи `minor` с 1 (например `1.3` -> `1.4`)
4. Запиши новата версия обратно във `VERSION` файла
5. Покажи на потребителя старата и новата версия
